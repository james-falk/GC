# Scenario 1 — Project setup: Lincoln Elementary Phase 2

**Duration:** ~90 seconds
**Persona:** Lena Torres, Project Manager

The story: Spartan just won the Lincoln Elementary renovation bid.
Lena spends 90 seconds standing up the project: owner, architect,
three subs, three subcontracts, and a seven-line schedule of values
imported from the CSV she already had in Excel.

---

## Beat 1 (00:00–00:08)

[Screen: Sign-in modal → dashboard lands. Zero state — empty metrics.]

> Lena just won the Lincoln Elementary renovation bid. Two-point-four
> million dollars, twelve-month timeline. She signs in to set up the
> project.

## Beat 2 (00:08–00:18)

[Screen: Click Organizations → Add organization. Type "Springfield Public
Schools", select type "Owner", fill contact email.]

> First — the project owner. Springfield Public Schools. She'll need
> them attached so owner-facing approvals route to the right inbox.

## Beat 3 (00:18–00:28)

[Screen: Add another organization → Northbridge Architecture, type "Architect".]

> And the architect — Northbridge Architecture. Architects sign off on
> change orders and notarized sworn statements, so they get their own
> magic-link inbox just like owners.

## Beat 4 (00:28–00:40)

[Screen: New project form. Fill project number "LE-2", name "Lincoln
Elementary Renovation Phase 2", contract amount 2,400,000.00, pick both orgs
from dropdowns. Submit.]

> Now the project itself. Two-point-four million, both organizations
> attached at creation so the audit trail starts clean from day one.

## Beat 5 (00:40–00:55)

[Screen: Subcontractors → Add three: Brothers and Bricks Masonry, Apex
Electric, Solid Mechanical. Use real-looking contact emails.]

> Three subs on this job. Brothers and Bricks for masonry, Apex
> Electric, Solid Mechanical. Each gets a directory entry — reusable
> across every future project.

## Beat 6 (00:55–01:08)

[Screen: Back to Lincoln Elementary → Subs tab → Add subcontract for each.
Brothers and Bricks at $420k, Apex at $185k, Solid at $310k. All status=active.]

> She attaches each sub to Lincoln Elementary with a contract. The
> contract amount sits at the original bid. Approved change orders
> will move the current amount — automatically — when we get there.

## Beat 7 (01:08–01:25)

[Screen: SoV tab. Click "Choose CSV", pick a pre-made lincoln-sov.csv.
Watch lines populate — seven lines, parent "3" with children "3a" and "3b".]

> The schedule of values. She's already got it in Excel — drag the
> CSV into the importer. Seven lines, a parent for masonry broken
> into brick and block, the rest flat. Done in three seconds.

## Beat 8 (01:25–01:35)

[Screen: Final SoV view. Show the KPI strip: Contract value $2.4M,
billed $0, 0 open COs, 3 subs, 0 pay apps awaiting. All tiles green/slate.]

> Project's stood up. Two-point-four million in scope, three active
> subcontracts, seven SoV lines, zero drift. That's day-one done in
> under two minutes.
